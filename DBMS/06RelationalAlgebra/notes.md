# Query Language
## Definition:
    - Now task is to store, retrieve and modify data in the data base.
    - 2 Ideas:
        - 1. Procedural
            - We tell the data we need and tell the steps to do to get that value.
            - Relational Algebra is model for this
        - 2. non-Procedural
            - We just tell what we want and we get it.
            - Relational Calculus is model for this.

    - SQL is 90% of Relational Algebra and 5% Relational Calculus.



## Relational Algebra:
    - It does not have duplication.
