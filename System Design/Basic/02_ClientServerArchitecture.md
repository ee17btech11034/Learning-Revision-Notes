# Client - Server Architecture

    - Client:
        - Someone who needs information
    - Server:
        - A machine that has that info and provides that to clients.
    
    - Advantages:
        - Central Resource Management
        - Scalability
        - Flexibility reach (anyone can check this)
    - Disadvantages:
        - Single point of failure
        - Network Congestion (wait if traffic increases)
        - Security Risk (Hacker can access the resources like DB, methods if all are in srver machine).
